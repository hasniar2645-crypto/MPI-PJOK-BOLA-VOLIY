ISI
- index.html: aplikasi MPI interaktif yang berjalan di browser.

CARA MEMBUKA
1. Ekstrak ZIP ini.
2. Buka folder MPI_Bola_Voli_HASNIAR.
3. Klik dua kali index.html; gunakan Chrome, Edge, atau Firefox.
4. Untuk mempublikasikan online, unggah index.html (atau seluruh folder) ke layanan hosting statis seperti GitHub Pages, Netlify, atau hosting sekolah.

FITUR
Apersepsi, asesmen awal, materi servis/passing bawah/smash/blocking, simulasi pilihan situasi, kuis dengan skor otomatis, asesmen akhir, refleksi, dan cetak/simpan PDF.

CATATAN

- Asesmen praktik tetap perlu diamati dan dinilai oleh guru.
- Simulasi adalah simulasi pilihan berbasis teks, bukan video atau animasi teknik gerak.
